================================================================================
🎯 EXEMPLOS DE USO
================================================================================

Exemplo 1: Análise Pré-Jogo
──────────────────────────
from main import SistemaGestiaoBanca

sistema = SistemaGestiaoBanca(banca_inicial=1000)

recom = sistema.analisar_pre_jogo(
    time_home="Porto",
    time_away="Benfica",
    prob_over_25=0.65,
    prob_over_05_ht=0.70,
    score=68,
    odds_esperada=1.75
)

print(recom)
# {
#   'pode_apostar': True,
#   'stake_recomendado': 95.50,
#   'ev': '+6.3%',
#   'confianca': 'ALTO'
# }

Exemplo 2: Registrar Aposta e Resultado
───────────────────────────────────────
aposta = sistema.registrar_aposta_realizada(
    partida="Porto vs Benfica",
    mercado="over_0.5_ht",
    odds_realizada=1.75,
    stake=95.50
)

sistema.registrar_resultado(
    aposta_id=aposta['aposta_id'],
    resultado="vencida",
    lucro_prejuizo=82.75
)

Exemplo 3: Dashboard
───────────────────
dashboard = sistema.get_dashboard_completo()

print(dashboard['resumo'])
# {
#   'banca_atual': 1082.75,
#   'roi_percentual': 8.3,
#   'win_rate': '100%'
# }

================================================================================
🌐 API REST ENDPOINTS
================================================================================

Após iniciar servidor: python services/api_antigravity.py

GET  /api/v1/banca           → Banca atual
GET  /api/v1/stats           → Estatísticas
GET  /api/v1/risco           → Análise de risco
GET  /api/v1/dashboard       → Dashboard completo
POST /api/v1/aposta          → Registrar aposta
POST /api/v1/aposta/<id>/resultado → Registrar resultado
GET  /api/v1/alertas         → Histórico de alertas

🆘 SUPORTE & TROUBLESHOOTING
================================================================================

→ pip install -r requirements.txt

API não responde
→ python services/api_antigravity.py (com debug=True)

Telegram não envia
→ Verificar token e chat_id em config

Dados não salvam
→ Verificar permissões de escrita em ./dados
